# Leonida Chapter 1 map

A fan-made, unofficial interactive map of sourced Chapter 1 cash spots, unique weapons, and notable cars in Grand Theft Auto VI.

This project is not affiliated with, endorsed by, or sponsored by Rockstar Games or Take-Two Interactive.

The base map is the official Leonida Map Poster (printable) published by Rockstar Games, available from [Rockstar’s VI media page](https://www.rockstargames.com/VI/media).

Pin locations are approximate and taken from public guides.
